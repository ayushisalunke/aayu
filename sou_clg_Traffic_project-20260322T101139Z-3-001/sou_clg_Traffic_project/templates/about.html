AI-Based Traffic Sign Recognition & Driver Assistance System

Project Overview

This MCA major project presents an AI-driven Traffic Sign Recognition System designed to simulate a driver assistance interface for intelligent transportation environments.

The system classifies 43 distinct road sign categories using a deep transfer learning architecture and provides real-time visual feedback through a modern dashboard interface.

Technical Architecture

  • Model Architecture: EfficientNet
  • Framework: TensorFlow / Keras
  • Loss Function: Categorical Crossentropy
  • Optimizer: Adam
  • Input Resolution: 224 × 224
  • Backend: Flask (Python)
  • Frontend: Bootstrap + Custom Dark UI
  • Deployment: Web-based Interface
  • Dataset: Multi-class Traffic Sign Dataset
  • Total Classes: 43

System Purpose

The primary objective of this system is to demonstrate how deep learning models can be integrated into intelligent driver assistance systems (ADAS) to enhance road safety and automated vehicle awareness.

This interface simulates an in-vehicle AI dashboard where road sign detection events are visualized in a structured and user-friendly manner.
